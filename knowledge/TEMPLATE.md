# 知识笔记统一模板

> 每个知识点一个文件，按以下结构整理。
> 重要规则：AI 生成的解释不能直接等同于已掌握的知识。只有你能独立解释并通过实验或推理验证之后，才把掌握状态改为"已掌握"。

```
# 知识点标题

## 1. 一句话定义
（用自己的话，一句话说清它是什么）

## 2. 核心原理
（记录 shape、stride、storage_offset 等之间的关系 / 机制 / 公式）

## 3. 最小代码示例
（保存可以独立运行的 Python 示例）

## 4. 我的理解
（用自己的话解释，不直接复制 AI 的答案）

## 5. 易错点
（例如：shape 相同，不代表 stride 相同）

## 6. 与其他知识的联系
（关联哪些已学/待学知识）

## 7. 实验验证
（记录输入、输出、shape、stride 和结论）

## 8. 掌握状态
未学 / 学习中 / 待验证 / 已掌握

## 9. 官方资料
（官方文档链接和对应章节）

## 10. 待解决问题
（还不能独立解释的问题）
```
