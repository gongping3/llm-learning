## 通用要求

1. **自己写**，不要先去看 vLLM 源码抄实现。做完再看，收获完全不同。
2. 每个项目必须留下：可运行代码、实验数据、结论（写进对应的 `knowledge/` 笔记）。
3. **记录失败与调试过程**，那比成功更有价值。
4. 完成标准里带"必须能回答"的问题，要能不看资料口头答出来。
